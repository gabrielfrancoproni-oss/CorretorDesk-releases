# CorretorDesk — downloads

Este repositório guarda **só os pacotes de instalação** do CorretorDesk (as "Releases"). O código-fonte não fica aqui.

## Como baixar
1. Abra o link que chegou no Telegram, ou a página **Releases** deste repositório.
2. Baixe o arquivo `CorretorDesk-v<versão>-<build>.zip` da versão mais nova.

## Como instalar
1. No CorretorDesk aberto: ⚙️ Configurações → ⚙️ Sistema → **Exportar Backup** (guarde o arquivo).
2. Feche o CorretorDesk.
3. Extraia o ZIP na **mesma pasta de sempre** do CorretorDesk, substituindo os arquivos quando o Windows perguntar.
   Seus dados ficam em outra pasta e não são apagados.
4. Abra pelo `iniciar.bat`.
5. Confira em ⚙️ Configurações → ⚙️ Sistema se a **Build** é a mesma do nome do arquivo.

Ficam aqui só as 5 versões mais recentes.
